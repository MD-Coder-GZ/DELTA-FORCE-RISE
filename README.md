Delta Force RISE SERIES 2026 — Сезон 2 (краткий перевод правил)

Этот репозиторий содержит краткий русский перевод ключевых пунктов официального rulebook турнира Delta Force RISE SERIES 2026 — Season 2.

Что внутри

· index.html — главная страница с переводом и навигацией.

· style.css — тёмный тактический стиль в духе Delta Force.

· README.md — описание проекта.

Как запустить локально

1. Открой index.html в браузере.

2. Или запусти простой локальный сервер, например:

python -m http.server

и открой http://localhost:8000.

Как выложить на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.

2. Загрузи туда файлы: index.html, style.css, README.md.

3. В настройках репозитория:

o Settings → Pages

o Source: main (или master) branch, folder: / (root)

4. Через пару минут сайт будет доступен по адресу: https://<твой-username>.github.io/<имя-репозитория>/
